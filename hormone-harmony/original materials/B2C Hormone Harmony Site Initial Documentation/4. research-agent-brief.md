## 2. Design Patterns & Visual Identity

### Color Palettes Observed

**Warm & Approachable (Majority):**
- Flo: Pink (#FF6B9D), coral, warm gradients
- Natural Cycles: Teal (#00C4A1), green
- Ovia: Purple (#8B5CF6), soft pastels

**Clinical & Trustworthy:**
- Clue: Deep purple (#6C3FB5), professional
- Allara: Muted teal, medical professionalism

**Recommendation for Hormone Harmony:**
Our sage green (#8BA888) + coral (#E8A598) + plum (#7B5A7D) palette aligns perfectly with the warm & approachable trend while differentiating from direct competitors. ✓ Validated.

### Typography Trends

**Headings:**
- Rounded sans-serif fonts (Outfit, Sofia Pro, Circular)
- Avoid sharp, angular fonts
- Weight: 600-700 for headings

**Body:**
- Clean sans-serif (Inter, Source Sans, Open Sans)
- 16-18px base size for readability
- 1.5-1.6 line-height

**Recommendation:**
Our planned Outfit (headings) + Inter (body) follows industry standards. ✓ Validated.

### Imagery Style

**What Works:**
- Real, diverse women (not stock "medical" photos)
- Natural lighting, warm tones
- Lifestyle contexts (yoga, journaling, nature)
- Authentic emotions (calm, confident, reflective)

**What Doesn't Work:**
- Sterile medical settings
- Lab coats and stethoscopes
- Overly polished, fake-looking stock photos
- Clinical/cold imagery

**Recommendation:**
Use warm, authentic lifestyle imagery as planned. Avoid clinical aesthetic.

### Layout Patterns

**Homepage Structures (Consistent Across Competitors):**
1. Hero with clear value prop + CTA
2. Validation/problem statement ("You're not alone")
3. Three-pillar benefits or features
4. How it works (3-4 step process)
5. Trust signals (privacy, medical expertise)
6. Testimonials
7. Final CTA
8. Footer

**Recommendation:**
Our IA aligns with proven patterns. ✓ Validated.

## 4. User Experience Patterns

### Dashboard Design

**What Users Expect:**
- Glanceable overview (today's status at a glance)
- Visual data (graphs, not just numbers)
- Symptom logging interface (quick, easy)
- Pattern recognition features
- Predictions/forecasts

**Best Practices Observed:**
- Dashboard > Chatbot (Flo learned this the hard way)
- Visual symptom selection (icons + sliders)
- Calendar view with color-coding
- Trend charts showing symptom correlations
- Daily "insights" or "tips" for engagement

**Recommendation:**
- Plan dashboard interface for future (Phase 2)
- Start with assessment and insights (Phase 1) ✓
- Prioritize visual data presentation

### Onboarding Flows

**Typical Steps:**
1. Welcome + value proposition
2. Data permissions request (with clear explanation)
3. Profile setup (basic info)
4. Health assessment (symptoms, cycle, goals)
5. Personalization questions
6. First insights/recommendations

**Best Practices:**
- Progress indicators (e.g., "Step 2 of 5")
- Skip options for sensitive questions
- Explanations of "why we ask" for each section
- Immediate value after completion

**Recommendation:**
- Design multi-step assessment with progress bar
- Include "why we ask" explanations
- Show sample insights before signup (preview value)

### Symptom Tracking UI

**Common Patterns:**
- Category-based (Physical, Emotional, Lifestyle)
- Icon-based selection (tap to log)
- Severity scales (1-5 or slider)
- Free-text notes option
- Quick log vs. detailed log options

**Top Logged Symptoms (from research):**
1. Flow (light/medium/heavy/spotting)
2. Mood (happy, sad, anxious, irritable, etc.)
3. Pain (cramps, headache, back pain)
4. Energy levels
5. Sleep quality
6. Skin changes (acne, dryness)
7. Digestive issues
8. Libido

**Recommendation:**
- Use icon-based symptom logging
- Include severity scales
- Prioritize most-logged symptoms
- Add free-text for unique symptoms

## 8. Pricing & Business Models

### Common Pricing Strategies

**Freemium Model (Most Common):**
- **Free tier:** Basic tracking, limited insights
- **Premium tier:** Advanced insights, predictions, content
- **Price range:** $5-15/month or $40-120/year

**Examples:**
- Flo: Free basic, $50/year premium
- Clue: Free basic, $60/year premium
- Natural Cycles: $90-120/year (required for FDA-cleared method)

**Subscription + Services:**
- Elektra Health: $99-250/month (telehealth included)
- Midi Health: $300 initial, $99/month (doctor consults)
- Allara Health: $149-199/month (PCOS care program)

**One-Time Purchase:**
- Some apps offer lifetime access ($50-100)

**Recommendation for Hormone Harmony:**
- **Phase 1:** Free assessment and educational content (build trust)
- **Phase 2:** Freemium with premium insights/tracking
- **Future:** Consider hybrid (education free + premium patch program)
