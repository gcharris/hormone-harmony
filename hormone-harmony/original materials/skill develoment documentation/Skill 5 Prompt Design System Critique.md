## **Skill 5 Prompt: Design System Critique**

```

@create-skill

Create a Skill called "Design System Critique"

**Purpose**: Provide UX-focused design feedback on visual hierarchy, spacing, color, and brand consistency. Use for design reviews and improvement suggestions.

**Evaluation Framework**:

1. **Visual Hierarchy**
   - What's the most important element? Is it obvious?
   - Size, contrast, position, whitespace
   - Heading scale creates rhythm
   - CTAs stand out from body content

2. **Spacing & Rhythm**
   - Consistent use of spacing scale
   - Related elements grouped
   - Generous whitespace (not cramped)
   - Vertical rhythm maintained

3. **Color & Contrast**
   - Primary color used for key actions
   - Secondary/accent colors used sparingly
   - Contrast meets WCAG AA
   - Color not sole indicator (icons/text included)

4. **Typography**
   - Font sizes create clear levels (H1 > H2 > H3 > body)
   - Line height readable (1.5 for body, 1.2 for headings)
   - Line length comfortable (45-75 characters)
   - Font pairing harmonious

5. **Brand Consistency**
   - Colors match brand palette
   - Tone matches brand (warm/clinical, playful/serious)
   - Component styles consistent across pages
```
