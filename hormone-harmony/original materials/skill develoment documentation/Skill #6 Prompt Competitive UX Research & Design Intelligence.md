## **Skill #6 Prompt: Competitive UX Research & Design Intelligence**

```
@create-skill

Create a Skill called "Competitive UX Research & Design Intelligence"

**Purpose**: Research competitor websites to analyze modern UI patterns, visual sophistication, trust-building strategies, and user experience best practices. Use findings to recommend specific design enhancements for website projects.

**Core Principles**:
- Research-first approach: Analyze 3-5 competitors before making recommendations
- Visual pattern documentation: Screenshot and describe successful UI elements
- Evidence-based recommendations: Every suggestion backed by competitor examples
- Modern design standards: Focus on current (2024-2025) UI trends and patterns
- User trust analysis: Identify how competitors build credibility and emotional connection

**Research Categories**:

1. **Visual Design Patterns**
   - Layout strategies (hero sections, grid systems, whitespace)
   - Color psychology and palette sophistication
   - Typography hierarchy and readability
   - Depth and dimensionality (shadows, gradients, layering)
   - Imagery style (photography vs illustration, composition, emotion)

2. **Interactive Elements**
   - Micro-interactions (hover states, transitions, animations)
   - Call-to-action strategies (button placement, copy, design)
   - Navigation patterns (mobile menus, sticky headers, breadcrumbs)
   - Form design (input styling, validation, progress indicators)
   - Loading states and feedback mechanisms

3. **Trust & Credibility Signals**
   - Social proof display (testimonials, reviews, case studies)
   - Credentials and certifications
   - Privacy and security messaging
   - Expert endorsements and partnerships
   - Transparent pricing and policies

4. **Content Strategy**
   - Headline formulas and copywriting patterns
   - Value proposition clarity
   - Emotional resonance and tone
   - Educational content integration
   - Call-to-action messaging

5. **Technical Excellence**
   - Performance indicators (load times, smooth animations)
   - Responsive design patterns
   - Accessibility implementations
   - Progressive enhancement strategies
   - Mobile-first considerations
```

```
**Research Process**:

1. **Initial Analysis (30 minutes per competitor)**
   - Homepage visual assessment
   - Navigation exploration
   - Mobile responsiveness check
   - Key page documentation (About, Features, Pricing)

2. **Pattern Documentation**
   - Screenshot key UI elements
   - Document color palettes
   - Note typography scales
   - Capture micro-interactions
   - Identify trust-building strategies

3. **Comparative Analysis**
   - Identify common patterns across competitors
   - Highlight unique differentiators
   - Document best-in-class examples
   - Note missed opportunities

4. **Recommendation Synthesis**
   - Prioritize findings (High/Medium/Low impact)
   - Provide specific implementation guidance
   - Include code examples where helpful
   - Link to competitor examples
```
