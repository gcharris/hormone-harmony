## Technical Implementation Guidelines

### Image Optimization Best Practices

#### File Size Optimization
```bash
# Current file sizes are 1.0-1.4 MB each
# Recommended optimization for web:

# Option 1: Use next-gen formats (WebP)
cwebp -q 85 yoga.png -o yoga.webp  # ~300-400 KB

# Option 2: Optimize PNG with compression
pngquant --quality=80-90 yoga.png  # ~600-700 KB

# Target: <500 KB per image for fast loading
```

**Priority:** Medium - current sizes are acceptable for quality, but optimization will improve load times

#### Responsive Image Strategy
```jsx
// Implement srcset for different screen sizes
<img
  src="/photos/yoga.png"
  srcSet="/photos/yoga-480.png 480w,
          /photos/yoga-768.png 768w,
          /photos/yoga-1024.png 1024w"
  sizes="(max-width: 768px) 100vw, 540px"
  alt="Woman practicing yoga for hormone balance"
  className="rounded-lg shadow-md"
  loading="lazy"  // Lazy load images below fold
/>
```

#### Accessibility Requirements

**Alt Text Guidelines:**
- **Descriptive:** What is shown in the image
- **Contextual:** How it relates to surrounding content
- **Concise:** 125 characters or less

**Examples:**

| Image | Good Alt Text | Why It Works |
|-------|--------------|--------------|
| `yoga.png` | "Woman practicing yoga for hormone balance and wellness" | Describes action + context |
| `Patch In Hand.png` | "Hormone Harmony patch held in hand, showing size and design" | Product detail + what user learns |
| `patient-confidence.png` | "Confident woman managing her health data with Hormone Harmony" | Emotional outcome + product |

**Avoid:**
- ❌ "Woman smiling" (too vague)
- ❌ "Image of yoga" (redundant "image of")
- ❌ "Photo123.png" (filename as alt text)

#### Performance Considerations

**Current Hero Image:**
- File: `hero-patch-model.png` (1.2 MB)
- Above fold: Must load immediately
- Recommendation: Keep as-is or optimize to ~800 KB

**Below-Fold Images:**
- Use `loading="lazy"` attribute
- Defer loading until user scrolls near
- Reduces initial page weight

**Total Page Weight Impact:**
```
Phase 1 (3 new images): +3.5 MB raw → ~1.5 MB optimized
Phase 2 (2 more images): +2.3 MB raw → ~900 KB optimized

Total Addition: ~2.4 MB optimized
Industry Standard: 3-5 MB for image-rich sites
```

**Verdict:** ✅ Acceptable - within industry standards for women's health sites

### Mobile Responsiveness Strategy

**Desktop (>768px):**
- Two-column layouts (image + text side-by-side)
- Images at 40-50% width
- Generous whitespace

**Tablet (768px):**
- Maintain two-column where space allows
- Slightly smaller images (100% of column width)

**Mobile (<768px):**
- Stack to single column
- Image above or below text (test which flows better)
- Full-width images with padding
- Consider slightly reduced image sizes for faster mobile load

**Example Responsive Code:**
```jsx
<div className="grid grid-cols-1 md:grid-cols-2 gap-8 md:gap-12 items-center">
  <div className="order-2 md:order-1">
    {/* Text content */}
  </div>
  <div className="order-1 md:order-2">
    <img
      src="/photos/yoga.png"
      alt="Woman practicing yoga"
      className="rounded-lg shadow-md w-full"
      loading="lazy"
    />
  </div>
</div>
```

**Mobile Consideration:** Image appears first on mobile (order-1), text second (order-2)
**Desktop:** Text left, image right (using md:order-*)

## Risk Assessment & Mitigation

### Potential Concerns

#### 1. Page Load Performance
**Risk:** Adding 3-5 images increases page weight significantly
**Mitigation:**
- Use WebP format (~70% smaller than PNG)
- Implement lazy loading for below-fold images
- Test on 3G/4G connections
- Target: <3 second load time on mobile

**Testing Plan:**
```bash
# Test with Lighthouse
npm run build
npx serve dist
# Run Lighthouse audit
```

#### 2. Image Quality on Retina Displays
**Risk:** 1x images may appear blurry on high-DPI screens
**Mitigation:**
- Provide 2x versions via srcset for retina screens
- Use high-quality source files (we have 1.0-1.4 MB originals)
- Test on iPhone/Macbook screens

#### 3. Diverse Representation
**Risk:** Limited diversity in current photography assets
**Mitigation:**
- Current assets show diverse contexts (yoga, professional, casual)
- Future: Acquire user testimonial photos from diverse users
- Future: Consider diversity photoshoot for additional contexts

**Current Assessment:** Adequate for MVP, plan for expansion

#### 4. Photography Feeling Staged
**Risk:** Even good photography can feel inauthentic if overproduced
**Mitigation:**
- Our assets use natural lighting and realistic contexts
- Avoid overly airbrushed or perfect imagery
- Mix product shots with lifestyle imagery
- Use candid moments vs. posed glamour shots

**Assessment of Current Assets:** ✅ Natural, authentic, warm lighting
