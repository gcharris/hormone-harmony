## Questions & Answers

**Q: Is the wordmark final?**
A: No, current wordmark is temporary (Outfit Semibold). Custom wordmark will be designed post-investor funding.

**Q: Why not show "Powered by Rithm"?**
A: For investor clarity. Standalone "Hormone Harmony" branding keeps pitch simple. Rithm co-branding can be added later if needed.

**Q: Can the logo be used on pitch deck slides?**
A: Yes! Use `/public/brand/logos/harmony-mark.svg` or PNG exports. See logo-usage-guidelines.md for placement rules.

**Q: What if investor asks about the logo?**
A: "Our current logo mark represents hormone balance through interwoven cycles. We're using a temporary wordmark and will develop a custom one post-funding."

**Q: Can colors be changed?**
A: No. Use only provided color variants (full color, mono white, mono plum). See logo-usage-guidelines.md.

**Q: How do I add logo to email signature?**
A: Export PNG at 2x resolution (64px height), embed inline. Use dark wordmark for light email backgrounds.
