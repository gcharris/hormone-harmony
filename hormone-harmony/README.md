# Hormone Harmony Web App

This is the Hormone Harmony B2C web app, built with React + Vite.

## Local development

```
npm install
npm run dev
```

## Build

```
npm run build
```

## Preview production build

```
npm run preview
```

## Deployment

Netlify is configured to publish the Vite build output from `dist`. Ensure the custom domain is managed in your DNS/Netlify settings.
